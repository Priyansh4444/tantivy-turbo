## Metadata owner and range coverage

SkipReader derives Clone over scalar metadata fields and an OwnedBytes view. OwnedBytes clones its independent slice pointer and immutable Arc-backed owner; advancing the cloned view cannot advance the real reader. The helper clones the actual borrowed skip reader, and every seek/advance belongs only to that clone. It never calls real seek_block/load_block/seek/advance, never touches the real decoder or position owner, and never reads or writes the real selected-block numeric cache. The only allowed real mutation is the existing query-owned PendingNative policy transition.

The range contract is explicitly still-unread leaves at a drained boundary. `floor >= up_to` and authoritative actual doc >= up_to prove zero before subtracting the exclusive endpoint; TERMINATED satisfies the latter. Otherwise start is max(floor, actual first-unread doc). For a noninitial selected reader, previous-last >= start conservatively returns global before inspecting remaining_docs for EOF. This covers a shallow reader selected beyond unread decoded postings. The initial block instead uses remaining_docs == doc_freq, correctly exempting the initialized previous-last 0 when doc 0 is legal. Remaining_docs decreases by complete-block counts during real forward metadata selection, so that identity does not reappear on a later block.

The cloned seek skips only complete blocks with inclusive last < start. Each trusted selected block contributes its whole certificate; the scan stops only after including a block whose inclusive end reaches up_to - 1. Whole first/last blocks intentionally over-cover clipped endpoints. If a full block does not cover the final endpoint, advancement continues through all intervening entries. A nonempty VInt tail has no selected pair and returns global, even when loaded. Missing/Basic pairs and saturated selected TF likewise return global. Empty relevant metadata contributes zero only after the too-late-reader guard. Saturation fallback is deliberately more conservative than some existing current-block native cases. No sentinel increment or endpoint feedback loop exists.
