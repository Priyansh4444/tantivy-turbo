# Wider-region design rubric

Parent accepted06 a674aaf2f6187f3010a135dc25fdacf9cab27e53.
Counters motivate investigation, not a speed claim. Compare whole shapes before
implementation; no hybrid arithmetic or stacked unverified candidate.

Score each criterion 1–5 with equal weight:

1. Exact semantic proof: every widened bound covers literal valid indexed leaves;
   preserve incoming publication, current threshold, physical deletes and cursors.
2. Ownership and interface: retain pre-cleanup information; keep pending replay
   fixed; numerical provenance belongs to the scorer; no caller choreography.
3. Concrete performance mechanism: remove measured repeated preparations while
   accounting for extra candidates, bounds, metadata traversal and short regions.
4. Compactness and scope: fixed index/format, bounded scratch, minimal hot record
   expansion, no per-region allocation or speculative selector/cache.
5. Meaningful verification: actual widened routes, later-block winners, stale-zero
   witnesses, configured/profile fallback, complete independent callback traces.

Choose a cheap isolated first attempt. A higher-quality bound is not automatically
faster. Preserve the runner-up for a later structurally distinct attempt if the
first fails. Root reads both packages and the fresh judgment before agreement.
