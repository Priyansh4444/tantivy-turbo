# Security policy

Please report suspected vulnerabilities privately through [GitHub's private
vulnerability reporting](https://github.com/Priyansh4444/tantivy-turbo/security/advisories/new).
Do not open a public issue for an unpatched vulnerability.

When possible, include the affected version or commit, a description of the
impact, and a minimal reproduction. Please remove credentials and other
secrets from any material you share. The project maintainers can then discuss
the report privately and coordinate a fix and disclosure.
